# Smart Parking Management System

## Description
A Smart Parking Management System designed to optimize parking space utilization for commercial shops. The system enables admins to allocate and manage parking slots, while tracking real-time vehicle entry and exit with validation to prevent invalid parking.

## Features
- Shop-wise parking slot allocation
- Real-time vehicle entry and exit tracking
- Automatic slot occupancy management
- Prevents parking for unallocated shops
- Billing based on parking duration

## Tech Stack
- Backend: Spring Boot (MVC)
- Frontend: JSP, HTML, CSS
- Database: MySQL
- ORM: Hibernate / JPA

## Use Case
Reduces parking congestion, avoids manual errors, and improves parking efficiency in malls and commercial complexes.

## How to Run
1. Configure MySQL database
2. Update `application.properties`
3. Run the Spring Boot application
4. Access via browser
